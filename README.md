# 우리동네 쿠폰마을

경기도 소상공인을 위한 **이벤트 쿠폰 기반 신규·단골 고객관리 프로그램**입니다.
손님은 쿠폰을 받고, 사장님은 손님 명단과 재방문을 자동으로 관리합니다.

## 화면 주소

| 주소 | 화면 |
|---|---|
| `/` | 동네 쿠폰 피드 (카테고리·지역·마감임박·인기순·내 주변) |
| `/region.html` | 관심 지역 설정 (경기 31개 시·군 먼저 오픈) |
| `/s/가게주소` | 가게별 쿠폰 랜딩페이지 (숏폼·QR·광고 링크용) |
| `/c/쿠폰번호` | 손님 쿠폰 화면 + 직원 확인(사용 처리) |
| `/me` | 마이페이지 (내 쿠폰, 단골 등급, 알림 수신 설정) |
| `/owner` | 사장님 관리 화면 (현황·사용처리·쿠폰 설정·손님 명단·알림톡 기록) |
| `/owner/poster` | 릴스 영상 · QR 포스터 만들기 |
| `/join` | 사장님 입점 안내 (영업용) |

체험 계정: 가게 주소 `hanuri` / 비밀번호 `demo1234` / 직원 확인 번호 `0000`

## 입점: 네이버 플레이스 링크만 넣으면 끝

사장님이 `/owner` → 가게 등록하기 → 플레이스 링크(또는 네이버 지도 '공유' 문구)를 붙여넣고 **가게 정보 불러오기**를 누르면
가게 이름·주소·전화·업종·지도 위치(내 주변 검색용)·리뷰 링크가 자동으로 채워집니다. 비밀번호만 정하면 업종별 첫 방문 쿠폰과 7일 골든타임 쿠폰이 켜진 상태로 바로 시작합니다.

- 네이버 **공식 지역 검색 API**만 사용합니다. 사진·메뉴·소개는 공식 통로가 없어 사장님이 직접 올립니다.
- 짧은 링크(naver.me)는 주소만 따라가 가게 번호를 확인하고, 가게 이름은 링크 미리보기 제목만 읽습니다(카카오톡 미리보기와 같은 수준).

## 신규·단골 고객관리 (사장님 화면 → 신규·단골 관리)

| 분류 | 기준 | 추천 행동 |
|---|---|---|
| 방문 전 | 쿠폰만 받고 아직 안 옴 | 방문 유도 쿠폰 |
| 신규 | 1번 방문 | 7일 안 재방문 쿠폰 |
| 단골 | 2번 이상 방문 | 단골 감사 히든 혜택 |
| 이탈 위험 | 30일 넘게 안 옴 | 보고 싶어요 쿠폰 |

이번 달 신규 수, 단골 비율, 방문 전환율, 이탈 위험 수를 숫자로 보여주고, 손님을 골라 쿠폰을 바로 보낼 수 있습니다(수신 동의 손님만, 같은 손님에게 7일에 1번).

## 내 주변

손님이 '내 주변'을 누르면 3km·5km·10km 안 가게를 가까운 순으로 보여주고, 가게 상세에 '내 위치에서 ○km'가 표시됩니다.
위치 권한을 이미 허락한 손님은 처음부터 카드마다 거리가 보입니다. 위치는 서버에 저장하지 않습니다.

## 자동으로 돌아가는 것

- 쿠폰 발급 즉시: 쿠폰 + 지도 링크 알림톡
- 이벤트 쿠폰 만료 2일 전 오전 11시: 리마인드
- 매장에서 쿠폰 사용 → 리뷰 유도 화면, **7일 골든타임 쿠폰** 자동 발급, 이웃가게 크로스 쿠폰 발급
- 사용 1시간 30분 뒤: 골든타임 1차 메시지 / 만료 전날 11시: 리마인드
- 30일 동안 다시 안 오면: 안부 + 시크릿 쿠폰
- 밤 9시~아침 8시에는 광고 메시지를 보내지 않음(다음날 11시로 미룸), 수신 동의한 손님에게만 발송

## 배포 (Netlify)

1. Netlify에서 이 저장소를 연결하면 끝 (빌드 명령 불필요, 데이터는 Netlify Blobs에 저장)
2. **Site settings → Environment variables** 에 아래 값을 넣으면 실제 기능이 켜집니다.

| 변수 | 용도 | 없으면 |
|---|---|---|
| `JOIN_CODE` | 사장님 가입 코드 (영업사원이 전달) | 누구나 가게 등록 가능 |
| `SOLAPI_API_KEY`, `SOLAPI_API_SECRET`, `SOLAPI_SENDER` | 솔라피 문자 발송 (인증번호·안내) | 테스트 모드: 인증번호가 화면에 표시, 메시지는 기록만 |
| `SOLAPI_PFID`, `ALIMTALK_TPL_ISSUED` 등 | 카카오 알림톡 (채널 ID, 승인된 템플릿 ID) | 문자로 발송 |
| `KAKAO_REST_KEY`, `KAKAO_CLIENT_SECRET` | 카카오 1초 로그인 | 버튼 숨김 (휴대폰 인증만) |
| `NAVER_CLIENT_ID`, `NAVER_CLIENT_SECRET` | 네이버 로그인 | 버튼 숨김 |
| `NAVER_SEARCH_ID`, `NAVER_SEARCH_SECRET` | 플레이스 링크 → 주소·전화·지도위치 자동 입력 (네이버 개발자센터 '검색' API) | 없으면 네이버 로그인 키로 시도, 그것도 없으면 이름·주소만 채움 |
| `SESSION_SECRET` | 로그인 암호 키 | 자동 생성 |
| `DEMO_SEED=off` | 체험용 가상 가게 끄기 | 가상 가게 10곳 표시 |
| `CRON_KEY` | 예약 발송 수동 실행용 | – |

알림톡 템플릿 종류: `ISSUED`(발급), `EVENT_D2`(만료 D-2), `GOLDEN`(골든타임 1차), `GOLDEN_REMIND`(골든타임 리마인드), `CHURN`(30일 안부).
템플릿 변수: `#{가게명}`, `#{혜택}`, `#{쿠폰링크}`, `#{만료일}`, `#{지도}`.

카카오/네이버 개발자 센터의 Redirect URI: `https://내사이트주소/api/auth/kakao/callback`, `/api/auth/naver/callback`

## 내 컴퓨터에서 실행

```bash
npm install
npm run dev     # http://localhost:8888
npm test        # 발급 → 사용 → 골든타임 → 30일 안부 흐름 자동 점검
```

## 구조

- `site/` 화면 (HTML·CSS·JS)
- `netlify/lib/` 업무 규칙 (`logic.mjs`), 서버 주소 처리 (`api.mjs`), 문자·알림톡 (`messaging.mjs`), 저장소 (`db.mjs`), 체험 데이터 (`seed.mjs`)
- `netlify/functions/api.mjs` 서버, `scheduler.mjs` 10분마다 예약 메시지 발송

## 광고 전용 이벤트 랜딩페이지 (`/e/가게주소`)

광고·SNS에 거는 한 장짜리 쿠폰 페이지입니다. 다른 가게로 빠지는 길 없이 **사진 → 혜택 → 남은 시간 → 대표 메뉴 → 쿠폰 받기**만 보여줍니다.
링크 끝에 `?ch=insta`, `?ch=daangn`처럼 경로를 붙이면 어느 광고로 들어왔는지 기록돼서
사장님 화면 **🔗 광고 링크** 탭에서 경로별 방문·가입·실제 매장 방문을 비교하고, 손님 명단에 유입 경로가 표시됩니다. 경로별 QR 이미지도 내려받을 수 있습니다.

## 고객관리 프로그램 (사장님 화면)

- **➕ 매장 적립**: 쿠폰 없이 온 손님도 전화번호만 누르면 손님 등록·방문 스탬프 적립 (2시간 안 중복 적립 방지)
- **👥 신규·단골 관리 → 상세**: 손님별 방문 기록·받은 쿠폰·메모·생일·태그
- **⚙️ 자동 발송**: N번째 방문 선물, 생일 쿠폰(며칠 전), 오래 안 온 손님 다시 부르기
- **📈 월간 리포트**: 신규·방문·재방문율을 지난달과 비교, 이달의 단골 TOP 5, 인쇄·PDF 저장

## 사진

체험 가게 사진은 위키미디어 커먼즈의 **퍼블릭 도메인(CC0·PDM)** 사진으로, 상업적 사용이 가능합니다. 출처는 `site/img/demo/CREDITS.json`에 있습니다.
실제 가게는 사장님이 가게 정보 탭에서 가게 사진과 메뉴별 사진(📷)을 올리면 그대로 보입니다.
